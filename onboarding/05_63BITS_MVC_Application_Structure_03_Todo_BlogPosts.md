# To Do Exercise

Having completed the full walkthrough of building the Products module — from database layer to presentation layer — you are now ready to independently build the next module: **BlogPosts**. As with the Products module, this will include both a List page and a Details page.

<br>

<font size="6">**Task: Build BlogPosts Module**</font>

<br>

## Blog Post Properties

Each blog post should include the following properties:

- Caption
- Text
- Cover Image
- Published flag

<br>

## Database Structure

When creating the database structure:

- Review the database naming rules carefully.
- Review the table design guidelines again.
- Since the blog post text may contain large content, use `nvarchar(max)` for the text column.

<br>

## Views

Static HTML templates for the BlogPosts module are available in the **wwwroot/html** folder. Use these files as the basis for building the Views.

<br>

Good Luck!
